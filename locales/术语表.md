## 二、OpenCC 会翻错的词（必须人工覆盖）

这几条是实测 `s2twp` 出来的**错译**，生成脚本里用 `TERM_FIX` 逐条替换：

| 简体        | OpenCC 输出（错） | 正确        | 原因                                              |
| ----------- | ----------------- | ----------- | ------------------------------------------------- |
| 账号 / 账户 | 賬號 / 賬戶       | 帳號 / 帳戶 | 台湾一律用「帳」                                  |
| 当前        | 當前              | 目前        | 「當前」是大陆用法                                |
| 镜像        | 映象              | 鏡像        | 「映象」是 image 的音译，mirror 用「鏡像」        |
| 记事本里    | 記事本里          | 記事本裡    | 「里」繁简同形，OpenCC 不敢动；方位词台湾写「裡」 |

## 三、`<code>` 里的东西一律不翻

分片字段名（`话数` / `导演` / `音乐` / `动画制作公司` / `系列构成`）、文件名
（`data/anime.manifest.json`）、URL、JSON 样本、`bgm_*` 存储键 —— 这些是**字面量**，
用户会照着写进表格或代码。翻成繁体就成了「另一个字段名」，对不上。

生成脚本对 `<code>…</code>` 做**先挖掉、转换完再放回**，所以语言包里这些片段
保持简体原样。校对时看到 `<code>` 里是简体，**是正确行为，不要改**。

## 四、标点

- 正文用全角 `，。：；！？`，与简体一致（繁简同形，无需转换）。
- 引号统一 `「」`（书名号、强调都走它）；`"…"` 只在引用原始 JSON / 文件名时出现。
- 括号用全角 `（）`；括号内是纯英文时保留半角 `( )`。

## 五、不翻译的内容

| 内容                                                            | 原因                                   |
| --------------------------------------------------------------- | -------------------------------------- |
| 语言按钮上的「简体中文 / 繁體中文 / English」                   | 各语言显示自己的母语名，这是 i18n 惯例 |
| `Bangumi`、`WPS`、`GitHub`、`Token`、`SID`、`URL`、`CSV`、`TXT` | 专有名词 / 缩写                        |
| 日志正文                                                        | 面向开发者排查，不进语言包             |
