### 阻塞风险（按发生概率排序）

| 风险 | 影响 | 触发条件 | 缓解措施 |
| --- | --- | --- | --- |
| **R1 · 覆盖率守卫中断** | `vitest --coverage` 删 `coverage/.tmp` 触发 bulk-delete 守卫（阈值 50），测试没跑、产物陈旧 | 跑覆盖率复核时未设环境变量 | 跑前设 `$env:CODEBUDDY_SAFE_DELETE_BULK_THRESHOLD='1000000'`；**切勿**置空 `CODEBUDDY_SAFE_DELETE_BULK_GUARD`（它是脚本路径，置空反而报 guard=unset） |
| **R2 · typecheck:tests 门禁** | 新增测试文件若有 TS 错误，gate 第一关即红 | `vi.fn(() => null)` 推断为 `null` 类型；`null as never` 锁死类型 | 用 `vi.fn((): unknown => null)`；`vi.hoisted` 里写 `null as { Name: string } \| null`；新文件须 0 错误 |
| **R3 · 难度误标** | 投入方向错（把易的当难拖延，或把真的 COM 当纯逻辑硬造假覆盖） | 未先扫依赖即定方案 | 每个 P2 任务动手前先 5 分钟依赖扫描；参考 `api.ts` 先例 |

| **R5 · 假宿主/假 DOM 状态泄漏** | 跨用例断言反向 | 模块级监听器 / 定时器未清理 | 复用 helpers 的 `clearDom`/`resetUtilityMock`；`beforeEach` 清时钟与监听器 |
