# 图标规范（Icon Guidelines）

> **版本**: v1.0
> **最后更新**: 2026-09-07
> **适用范围**: 全部 UI 页面（`panel.html` / `settings.html` / `enrich.html` / `panel-preview.html`）与动态生成的对话框内容

---

## 1. 图标体系总览

本项目使用两套图标，各有明确边界：

| 体系              | 形式                       | 使用位置                           | 规范来源     |
| ----------------- | -------------------------- | ---------------------------------- | ------------ |
| Ribbon 功能区图标 | SVG 文件（`images/*.svg`） | WPS 功能区按钮                     | 见 §6        |
| 顶栏快捷按钮图标  | 内联 SVG（16×16 线性风格） | 顶栏按钮（保存/导出/设置等）       | 见 §6        |
| 页面内容图标      | emoji 字符                 | 导航、区块标题、按钮文字、状态提示 | 本文档 §2–§5 |

**emoji 与 SVG 的边界**：

- emoji 用于「页面内内容」：导航项、区块标题、带文字按钮的前缀、状态/提示符号。
- SVG 用于「纯图标按钮」：无文字标签、依赖 `aria-label` / `title` 的顶栏与功能区按钮。
- **禁止在纯图标按钮中使用 emoji**：emoji 渲染宽度不可控、无法统一描边风格，会导致按钮视觉不一致。

---

## 2. emoji 选择标准

1. **语义优先**：优先选择语义明确、跨平台理解一致的 emoji；不选用冷门或多义 emoji。
2. **一义一图标**：一个核心语义只对应一个图标；同语义跨页复用允许，不同语义不得共用同一图标。
3. **跨页一致**：`panel` / `settings` / `enrich` 三页面中，同语义必须使用同图标（如「数据预览」统一 `👁️`、「远程仓库」统一 `🗄️`）。
4. **导航 = 标题 = 主按钮**：同一功能区块的导航图标、区块标题图标、主按钮图标必须一致。
5. **装饰与操作分离**：`💡` `📌` `ℹ️` 等「提示符」仅用于辅助说明文字，不参与操作图标的唯一性约束。

## 4. 变体选择符（VS16）规范

Unicode 将字符分为「默认文本呈现」与「默认 emoji 呈现」两类：

- **必须追加 `U+FE0F`**：默认文本呈现的码点，追加 VS16 强制以彩色 emoji 渲染，否则显示为黑白文本符号。
- **禁止追加 `U+FE0F`**：默认 emoji 呈现的码点，追加 VS16 冗余且无必要。

## 5. 使用规则

1. **导航 = 标题 = 主按钮**：功能区块的导航图标、区块标题图标、区块主按钮图标必须一致（如「数据预览」导航 `👁️`、标题 `👁️`、预览按钮 `👁️`）。
2. **跨页一致**：同语义图标在三个页面必须一致；`panel` / `settings` / `enrich` 之间不得出现同语义不同图标。
3. **文本跟随**：按钮的 emoji 与文字之间保留一个空格（如 `📤 上传同步`）。
4. **无障碍**：纯图标元素必须配 `aria-label` / `title`；带文字按钮不强制。
5. **新增图标流程**：先查 §3 映射表 → 已有语义必须复用 → 确需新语义时按 §2 标准选择并登记到映射表。

## 6. SVG 图标规范（Ribbon 与顶栏）

### 6.1 顶栏快捷按钮（内联 SVG）

- **尺寸**：统一 16×16px（`viewBox="0 0 16 16"`）
- **风格**：线性（stroke）为主，填充（fill）为辅
- **颜色**：使用 `fill="currentColor"`，随主题自动适配
- **无障碍**：无文字标签时使用 `aria-label` 替代（如「保存所有配置」）

### 6.2 Ribbon 功能区图标（`images/*.svg`）

- **来源**：统一使用 iconfont.cn 下载的同风格线性图标集，保证整套按钮视觉一致。
- **画布**：`viewBox="0 0 1024 1024"`，WPS Ribbon 自动缩放显示。
- **颜色**：品牌蓝 `#1296db` 描边/填充（与现有 `sync.svg` / `undo.svg` / `enrichPage.svg` 一致），不使用深色阅读器（`data-darkreader-*` 属性仅存在于历史文件，新图标不得引入）。
- **分发**：由 `GetBangumiImage` 按 `control.Id` 映射（`ts/ribbon.ts` 的 `ICON_PATHS`，index.html 有同源占位表），不参与页面 emoji 约束。
- **新增流程**：从 iconfont 挑选与现有图标同一作者/同一笔画风格的文件 → 存入 `images/` → 登记到 `ICON_PATHS` 与 `index.html` 占位表 → 清理未引用文件。
- **当前图标集**：`panel.svg`（打开面板）/ `sync.svg`（上传同步）/ `token.svg`（设置 Token）/ `TestToken.svg` / `CopyToken.svg` / `key.svg` / `user.svg` / `link.svg`（打开收藏页）/ `github.svg`（数据同步）/ `undo.svg`（撤销同步）/ `settings.svg`（设置）/ `enrichPage.svg`（新番表富化）/ `btnClearColors.svg`（清除颜色）/ `newFromTemp.svg`（默认兜底）。

## 7. 常见错误（反例）

| 反例                                          | 说明         | 正确做法                          |
| --------------------------------------------- | ------------ | --------------------------------- |
| 数据预览：panel 用 `📋`、enrich 用 `👁️`       | 跨页不一致   | 统一 `👁️`                         |
| 远程数据同步：panel 用 `📥`、settings 用 `🗄️` | 跨页不一致   | 统一 `🗄️`（`📥` 保留给下载/收藏） |
| `⚡` 不带 VS16                                | 黑白文本显示 | 使用 `⚡️`                         |
| `✋` 不带 VS16                                | 黑白文本显示 | 使用 `✋️`                         |
| `📋` 同时表示复制 / 数据预览 / 富化记录       | 一图标多义   | 复制=`📋`、预览=`👁️`、记录=`📊`   |
