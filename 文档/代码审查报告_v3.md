## 三、发现的问题列表

### 3.1 严重问题 (Critical)

#### 问题 1: 使用 document.write 加载脚本 ⚠️

**位置**: `main.js` 第2-6行

```javascript
document.write("<script language='javascript' src='js/util.js'></script>");
document.write("<script language='javascript' src='js/ribbon.js'></script>");
// ...
```

**问题分析**:
- `document.write` 在页面加载后执行会覆盖整个文档
- 存在 XSS 安全风险
- 不支持 ES6 模块加载
- 脚本加载顺序难以控制

**建议**: 使用动态脚本加载或 ES6 模块导入

---

#### 问题 2: Token 加密强度不足 ⚠️

**位置**: `js/util.js` 第187-266行

```javascript
function multiXor(text, keys) {
    let result = "";
    for (let i = 0; i < text.length; i++) {
        let key = keys[i % keys.length];
        result += String.fromCharCode(text.charCodeAt(i) ^ key);
    }
    return result;
}
```

**问题分析**:
- XOR 加密可被轻易逆向破解
- 密钥硬编码在代码中
- 校验和算法过于简单

**建议**: 
- 使用 Web Crypto API 进行 AES 加密
- 或使用 CryptoJS 库
- 考虑使用浏览器原生的 credential storage

---

#### 问题 3: 大量空 catch 块 ⚠️

**位置**: 多个文件中


## 四、安全隐患分析

### 4.1 已识别安全风险

| 风险类型 | 严重程度 | 位置 | 描述 |
|---------|---------|------|------|
| XSS | 高 | main.js | document.write 可能导致 XSS |
| 敏感数据泄露 | 高 | util.js | Token 加密强度不足 |
| CSRF | 中 | scraping.js | 跨域请求配置不当 |
| 注入攻击 | 中 | bangumi.js | 缺少输入验证 |
| 信息泄露 | 低 | 多处 | 调试信息可能泄露敏感数据 |

### 4.2 CORS 问题详解

**问题代码** (`js/sync/scraping.js` 第117-121行):

```javascript
let url = "https://bgm.tv/" + userId + "?tab=collect";
xhr.open("GET", url, true);
xhr.setRequestHeader("Cookie", "chii_secerv_token=" + token);
xhr.withCredentials = true;
```

**风险**: 
- 跨域请求到 bgm.tv
- 发送 Cookie 凭证
- 目标服务器可能阻止跨域请求

**建议**: 
- 使用官方 API `/user/{id}/collection` 替代网页抓取
- 使用 Authorization Header 而非 Cookie

## 五、性能优化建议

### 5.1 已识别性能问题

| 问题 | 位置 | 描述 | 建议 |
|------|------|------|------|
| 同步请求阻塞 | bangumi.js | 同步 XHR 阻塞 UI | 改用异步请求 |
| 重复 DOM 查询 | taskpane.js | 频繁查询相同元素 | 缓存 DOM 引用 |
| 缓存未失效 | syncRecord.js | 缓存同步机制不完善 | 增加缓存失效逻辑 |
| 大量同步写入 | bangumi.js | 每行单独写入 Excel | 批量操作 |

### 5.2 具体优化方案

#### 优化 1: 改用异步 API 请求

```javascript
// 当前 (同步，阻塞)
function bgmRequestSync(method, endpoint, body, token) {
    xhr.open(method, url, false);  // false = 同步
    xhr.send(body);
    return { code: xhr.status, ... };
}

// 建议 (异步)
async function bgmRequest(method, endpoint, body, token) {
    return new Promise((resolve, reject) => {
        xhr.open(method, url, true);  // true = 异步
        xhr.onload = () => resolve({ code: xhr.status, ... });
        xhr.onerror = () => reject(new Error('Network error'));
    });
}
```

#### 优化 2: 缓存 DOM 引用

```javascript
// 当前 (每次调用都查询)
function showToast(message, type) {
    let toast = document.getElementById("toast");  // 每次都查询
}

// 建议 (缓存引用)
const toast = document.getElementById("toast");
function showToast(message, type) {
    // 使用缓存的 toast
}
```

#### 优化 3: 批量 Excel 操作

```javascript
// 当前 (逐行写入)
for (let i = headerRow + 1; i <= lastRow; i++) {
    cell.Value = "成功";
}

// 建议 (批量操作)
ws.Range("C2:C100").Value = successArray;
```
