#### 问题 2：API 请求使用同步方式可能阻塞 UI

**文件**: `js/bangumi.js` 第 664-727 行

```javascript
// bgmRequest 函数声明为 async，但实际使用同步方式
xhr.open(method, BGM_API_BASE + endpoint, false); // false = 同步请求
```

**影响**: 同步 XMLHttpRequest 会阻塞浏览器线程，大数据量同步时可能导致 WPS 无响应

**建议修复**:
```javascript
// 改为真正异步请求
xhr.open(method, BGM_API_BASE + endpoint, true); // true = 异步
xhr.onload = function() { /* 处理结果 */ };
xhr.onerror = function() { /* 处理错误 */ };
```

或使用分批处理队列：
```javascript
async function batchProcess(items, batchSize = 10) {
    for (let i = 0; i < items.length; i += batchSize) {
        const batch = items.slice(i, i + batchSize);
        await Promise.all(batch.map(item => processItem(item)));
        await sleep(1000); // 批次间隔
    }
}
```
