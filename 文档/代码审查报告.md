## 三、发现的问题

### 3.1 严重问题 (High)

#### 问题 1：JSON 字符串拼接存在注入风险

**文件**: `js/bangumi.js` 第 544-660 行

```javascript
// 问题代码
parts.push('"comment":"' + jsonEscape(comment) + '"');
// 手动拼接 JSON 容易出错
```

**影响**: 虽然有 `jsonEscape` 函数进行转义，但手动拼接 JSON 方式不健壮

**建议修复**:
```javascript
// 改用 JSON.stringify 方式
const payload = {
    type: typeValue,
    rate: ratingValue,
    comment: commentValue,
    // ...
};
parts.push(JSON.stringify(payload));
```

---

#### 问题 2：API 请求使用同步方式可能阻塞 UI

**文件**: `js/bangumi.js` 第 664-727 行

```javascript
// bgmRequest 函数声明为 async，但实际使用同步方式
xhr.open(method, BGM_API_BASE + endpoint, false); // false = 同步请求
```

**影响**: 同步 XMLHttpRequest 会阻塞浏览器线程，大数据量同步时可能导致 WPS 无响应

**建议修复**:
```javascript
// 改为真正异步请求
xhr.open(method, BGM_API_BASE + endpoint, true); // true = 异步
xhr.onload = function() { /* 处理结果 */ };
xhr.onerror = function() { /* 处理错误 */ };
```

或使用分批处理队列：
```javascript
async function batchProcess(items, batchSize = 10) {
    for (let i = 0; i < items.length; i += batchSize) {
        const batch = items.slice(i, i + batchSize);
        await Promise.all(batch.map(item => processItem(item)));
        await sleep(1000); // 批次间隔
    }
}
```

---

#### 问题 3：硬编码 API Base URL 重复定义

**文件**: `js/bangumi.js` 第 7 行, `js/syncRecord.js` 第 732 行

```javascript

const BGM_API_BASE = "https://api.bgm.tv";

// syncRecord.js 中也有
const BGM_API_BASE = "https://api.bgm.tv"; // 第732行
```

**建议修复**:

```javascript
const BGM_CONFIG = {
    API_BASE: "https://api.bgm.tv",
    REQUEST_DELAY: 800,
    // 其他配置...
};
```

### 5.2 错误处理优化

1. **统一错误类型**: 定义自定义错误类
2. **增加错误日志**: 使用结构化日志记录
3. **错误边界**: UI 交互添加 try-catch 包裹

```javascript
class BGMError extends Error {
    constructor(message, code, details) {
        super(message);
        this.name = 'BGMError';
        this.code = code;
        this.details = details;
    }
}

// 使用
try {
    await syncFromBangumi();
} catch (e) {
    if (e instanceof BGMError) {
        showAlertDialog("同步失败", e.message);
        logError(e.code, e.details);
    }
}
```

### 5.3 性能优化

1. **批量操作优化**: 减少 Excel 单元格读写次数
2. **缓存优化**: 使用 LocalStorage 缓存频繁访问的数据
3. **分页加载**: 大数据集使用虚拟滚动
4. **异步处理**: API 请求改为真正异步，分批处理

```javascript
// 批量写入优化示例
function batchWrite(sheet, data) {
```

### 5.4 安全优化

1. **参数验证**: 所有用户输入添加验证
2. **敏感信息**: Token 存储改用更安全的方式
3. **输入转义**: 所有字符串拼接改用模板或 JSON.stringify

```javascript
// 参数验证示例
function validateUserId(userId) {
    if (!userId || typeof userId !== 'string') {
        throw new BGMError('用户ID不能为空', 'INVALID_INPUT');
    }
    if (!/^\d+$/.test(userId)) {
        throw new BGMError('用户ID必须是数字', 'INVALID_INPUT');
    }

}
```
