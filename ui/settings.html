🎨 外观与导航

深色 / 浅色点一下就以按钮为中心扩散切换；「跟随系统」自动匹配操作系统外观； 「定时」按下面两个时刻每天自动切换。

两个时刻之间是浅色，其余时间深色（例：07:00 浅 → 19:00 深）。支持跨零点 （深色 02:00、浅色 08:00 表示夜间深色）。

🧩 模块排序

调整各页面功能模块的显示顺序。侧栏导航与主区模块会同步重排，调整后立即保存并同步到对应页面。支持 ↑↓ 按钮（键盘可达）与鼠标拖拽两种方式。

✨ 富化预览

控制「新番表富化」页数据预览的视觉呈现：周几颜色、集数阈值徽章颜色、标签/首播/平台着色，以及需要过滤的噪声关键词。

集数等于此值时显示橙色徽章。默认 1。

集数等于此值时不显示颜色；大于此值显示绿色徽章；小于此值（且不等于单集阈值）显示黄色徽章。默认 12。

包含任一关键词（子串匹配）的播放平台/标签将被过滤掉。多个关键词用换行或逗号分隔。已默认过滤「示例」「新番表 by Hazx」「版权平台标注示例」等噪声。

⚙️ 功能开关

原先散在各工具页面内的全局开关集中到此统一管理。各页面每次加载工作表前会重读此处配置，保存后切到对应页面操作即生效。

自动模式按日期源识别最新季度；手动模式切到高亮页后指定年月。

📁 默认路径

这两个路径只作记忆与提示：导出配置时会在提示里告知保存位置，导入配置时会显示在文件选择框的标题上。 WPS 任务窗格走浏览器下载通道、文件选择框也不支持指定初始目录，因此两者都不会自动写入或跳转到该路径。

📜 日志偏好

低于所选级别的日志不会被记录，可减少运行噪音。此项控制「记录什么」；查看与筛选已记录日志请到主面板的「记录与日志」模块。

📦 配置管理

导出会下载配置文件并复制到剪贴板；导入支持从粘贴的 JSON 恢复；重置会清空所有已保存配置，请谨慎操作。

导出范围：Token、用户 ID、GitHub 仓库配置，以及全部工具页面的偏好 —— 外观与导航、同步选项、默认路径、日志级别、富化预览、番剧高亮（含目标工作表与锁定）、条件格式（含规则库、策略与目标工作表）、数据清理的规则开关。

不在导出范围：各页当前锁定的工作表实例（`bgm_locked_*`，属会话态）、数据清理里按工作簿记住的勾选（`bgm_clean_sheets:`，键里是文件路径，换机器对不上）。

📤 数据导出

把各工具的日志与记录导出为文件：CSV 可直接用 Excel 打开（带 BOM，中文不乱码）， TXT 适合在记事本里快速查看。三个工具页面各自也有就近的导出按钮。

ℹ️ 关于

Bangumi 同步工具 v2.0
用于在 Excel 中管理 Bangumi 动漫数据，支持：
• 上传同步（Excel → Bangumi）
• 数据同步（远程仓库 → Excel）
• 收藏下载（Bangumi → Excel）
• 新番表富化 / 数据清洗

本页只保留「跨会话生效的长期偏好」；Token、远程仓库、冲突策略等本次操作参数位于各操作页面。
