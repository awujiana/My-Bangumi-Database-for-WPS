🎨 外观与导航

深色 / 浅色点一下就以按钮为中心扩散切换；「跟随系统」自动匹配操作系统外观； 「定时」按下面两个时刻每天自动切换。

两个时刻之间是浅色，其余时间深色（例：07:00 浅 → 19:00 深）。支持跨零点 （深色 02:00、浅色 08:00 表示夜间深色）。

🧩 模块排序

调整各页面功能模块的显示顺序。侧栏导航与主区模块会同步重排，调整后立即保存并同步到对应页面。支持 ↑↓ 按钮（键盘可达）与鼠标拖拽两种方式。

每组顶部的「🧭 功能导航（侧栏）」也能点 👁️ 隐藏——把整条侧栏收掉、主区铺满宽度， 适合窄任务窗格；隐藏后回到这里点 🚫 即可恢复（每页独立记录）。

⌨️ 快捷键

键盘快捷键在所有页面生效；焦点在输入框 / 下拉框里时不抢键。点右侧组合按钮后按下新按键即可改绑，Esc 取消；与其它动作重复的组合不会保存，并在下方提示占用者。

👤 账号

记录多个 Bangumi 账号的 Token，之后可长按右上角头像一键切换。切换只改写当前生效的 Token / 用户 ID，表格数据与已同步内容不受影响。

「记录当前账号」把现在生效的 Token 与识别到的用户 ID 存成一条档案（同一账号重复记录只更新，不重复）。最多保留 8 个。

⚙️ 功能开关

原先散在各工具页面内的全局开关集中到此统一管理。各页面每次加载工作表前会重读此处配置，保存后切到对应页面操作即生效。

自动模式按日期源识别最新季度；手动模式切到高亮页后指定年月。

🎨 条件格式

条件格式页「工作表规则 → 自动聚类」按这里的口径分组。改完口径回到条件格式页再点一次「自动聚类」即按新口径重排（聚类只改本地视图分组，不动工作表上的规则）。

「按列」取应用范围的起始列（如「列 J」），「按行」取起始行（如「行 2」）；范围解析不出列 / 行时该条规则留在「未分组」。

条件格式页「工作表规则 → 🔗 合并重复项」按这里的口径合并：同公式、同列的多条单行规则并成一条。 「仅连续行」只合并行号连续的一段（2,3,4 → J2:J4），断开的行保持原样；「强行并成一块」取最小到最大一次覆盖， 中间空行也会被加上格式，差距大时要留意。

📁 默认路径

这两个路径只作记忆与提示：导出配置时会在提示里告知保存位置，导入配置时会显示在文件选择框的标题上。 WPS 任务窗格走浏览器下载通道、文件选择框也不支持指定初始目录，因此两者都不会自动写入或跳转到该路径。

📜 日志偏好

低于所选级别的日志不会被记录，可减少运行噪音。此项控制「记录什么」；查看与筛选已记录日志请到主面板的「记录与日志」模块。

📦 配置管理

一键导出：下载 bgm-config-日期.json 并复制到剪贴板；一键导入：粘贴该文件 JSON 即可恢复。重置会清空所有已保存配置，请谨慎操作。

导出范围：Bangumi Token 与多账号列表（含用户资料与过期时间）、GitHub 仓库配置（含同步源类型、Gist ID、分片选择、同步策略）、外观（主题 / 定时切换 / 模态框按钮位置）、导航（图标模式 / 分块排序 / 折叠隐藏）、快捷键绑定、同步选项、默认导入导出路径、日志级别、富化（预览设置 / 自动探测）、番剧高亮（列映射 / 模式 / 筛选范围 / 非动漫）、条件格式（规则库 / 应用策略 / 目标工作表 / 聚类与合并口径 / 分组命名 / 锚定与固定记录）、数据清理的规则开关。

不在导出范围（刻意的，非遗漏）：会话态与缓存 —— 各页锁定的工作表实例 bgm_locked_sheet_*、面板显示信号 bgm_panel_shown_at、COM 卡顿观测 bgm_com_stall_*、数据上下文 bgm_data_context、目标探测缓存 bgm_target_detect_cache；以及按工作簿记住的清理勾选 bgm_clean_sheets:（键里是本机文件绝对路径，换机器对不上，到新机器重新勾选即可）。

更新会不会丢配置：所有配置存在 WPS 的 PluginStorage（按加载项 ID 存放），更新插件（替换加载项目录 / 覆盖 dist）不会清除，规则库、锚定与固定记录、 账号与偏好都会原样保留；只有卸载加载项、清理 WPS 缓存或换机器才会丢 —— 这些场景用上面的导出 / 导入兜底。各工具的运行记录（同步 / 富化 / 清理日志）在「数据导出」里另行导出为 CSV / TXT。

📤 数据导出

把各工具的日志与记录导出为文件：CSV 可直接用 Excel 打开（带 BOM，中文不乱码）， TXT 适合在记事本里快速查看。三个工具页面各自也有就近的导出按钮。

ℹ️ 关于

My Bangumi Database for WPS v2.1.0
用于在 WPS 表格中管理 Bangumi 番组数据，支持：
• 上传同步（WPS 表格 → Bangumi）
• 数据同步（远程仓库 → WPS 表格）
• 收藏下载（Bangumi → WPS 表格）
• 新番表富化 / 数据清洗 / 番剧高亮 / 条件格式管理

本页只保留「跨会话生效的长期偏好」；Token、远程仓库、冲突策略等本次操作参数位于各操作页面。

从 GitHub Release 检查新版本；下载更新包后按日志提示覆盖安装。
