同步记录会保存在"同步记录"工作表中，包含：名称、URL、SID、类型、同步时间等

🌐 GitHub 仓库同步

从 GitHub 公开仓库下载 JSON 数据，按 SID 增量合并到当前工作表（新增+更新，不删除）。

JSONL 格式：每行一个 JSON 对象（无外层数组括号，无逗号分隔）
{"sid":"12345","name":"...","type":2,"score":8,"tags":["..."],"comment":"...","episode":12}
{"sid":"67890","name":"...","type":3,"score":9}
type: 1=想看 2=在看 3=看过 4=搁置 5=抛弃
默认仓库：awujiana/Bangumi-Archive-Anime-Excel-to-sync/main/data.jsonl
示例 Raw URL：https://raw.githubusercontent.com/{owner}/{repo}/{branch}/{path}

📖 使用引导

1设置 Token（只需设置一次）
2确保 Excel 包含必填列
3选择工作表和行范围
4点击"同步到 Bangumi"

📋 数据格式要求

列名（支持模糊匹配）说明必填
Bangumi_URL / bgmBangumi 条目链接✅ 必填
是否看完 / 观看状态是/否/在看
完播时间 / 看完时间如 2024-01-01
打分 / 评分1-10 分
感想 / 评价 / 简评个人评论
标签 / 分类用 | 、/ 分隔
特典 / 印象用 | 、/ 分隔
集数 / 看到如 1-12
