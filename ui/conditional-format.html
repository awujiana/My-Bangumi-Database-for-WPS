🎯 目标工作表

规则库是全局的，这里选「应用到哪张表、从哪张表读既有规则」： 先选目标工作簿，再在二级菜单里选该工作簿下的工作表。

👀 工作表规则

目标工作表现在就有的条件格式，按优先级排列（靠前先生效）。 可以直接管理：勾选后批量导入 / 删除，拖动行调整优先级，右键还有「如果为真则停止」等操作； 每条都能 ✎ 编辑（范围 / 公式 / 颜色）和 ⧉ 复制成新规则，改完立刻写回工作表。 数据条 / 色阶 / 图标集等类型插件无法重建，双策略会按你的选择处理。
点「⛶ 只显示此模块」进入**专注模式**：本页只显示这一块（顶栏收起、占满窗口）， 底部控制条可上下切换模块或退出；任务窗格在侧边，不挡表格主区。
📌（组标题上）= 锚定整列：把该组规则的应用范围改写成 $J:$J（多列 $J:$L），公式不变，行增删不再影响；📎 固定单元格 = 钉到单个 $J$5，删行删列后仍只作用于该单元格。两者都记在 PluginStorage 里，随「设置 → 配置管理 → 导出配置」一起备份，更新插件不会丢。

☑️ 我的规则

这里是存在本地、可复用的规则库（不在这张表上）。 拖动行即可调整顺序，顺序即优先级（靠前先生效）。 取消勾选 = 隐藏（留在库里不应用）。⧉ 复制会把规则写进系统剪贴板，同时可在本页「粘贴」出副本。 📥 导入工作表规则 = 把当前表已有的条件格式挑进来；按钮右侧 ▾ 还有从文件导入（项目「导出规则 → 导出到文件」得到的 .json，跨表 / 跨电脑迁移走这条）和从文本导入（粘贴 JSON）。 这里的 ✎ 只改本地库，不会立刻写表（「工作表规则」里的 ✎ 才直接写表）； 改完点「🖌️ 应用与修复 → 应用条件格式」才写进工作表——每次改动后会弹提示再说明一次。

📦 默认规则集

一键生成 6 条：当前季名称填绿（自维护 TODAY 公式，跨季度不用改）+ 日期格式错误标红 + 四季分色。依赖目标表识别到「开播季度」与「名称」列，公式锚定表头行下一行。

🖌️ 应用与修复

应用 = 先读目标表现有规则 → 清空重建（幂等，重复点不会叠出重复规则；删行搞乱范围后 重点一次即修复）。检测到你手工建的规则时会先弹框列出，让你选「清掉后应用」或「保留手工规则」。
